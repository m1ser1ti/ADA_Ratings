# Security policy

If you find a vulnerability in ADA Ratings, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/m1ser1ti/ADA_Ratings/security/advisories/new)
instead of opening a public issue.

Please include the steps to reproduce it and what an attacker could do with it.
You should get a reply within a few days. Only the live site at
https://www.adaratings.net and the `main` branch are supported.
